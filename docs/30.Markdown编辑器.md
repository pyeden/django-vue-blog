# 30. Markdown 编辑器

## 本章目标
- 在浏览器里写 Markdown。
- 实时预览。
- 支持标题、粗体、链接、代码块、引用、列表。

## 原教程怎么做
原教程在后台和前台接 CKEditor，用富文本工具栏；代码高亮用 Prism 插件。它解决的是“不会 Markdown 的人也能排版”。

## 本实作怎么做
前台改成 Markdown 编辑器 + 实时预览，后台仍可用 Django admin 编辑纯文本。`ArticleEditor.vue` 的结构：

- 左侧：标题、栏目、标签、封面、正文 textarea。
- 工具栏：`H1/H2/B/I/链接/代码块/引用/列表`，通过 `selectionStart/selectionEnd` 在光标处插入标记。
- 右侧：`renderMarkdown(form.body)` 后用 `MarkdownBody` 渲染，`marked + DOMPurify` 清洗。

保存时只提交 Markdown 源文，后端 `render_markdown` 统一生成 `body_html`，保证详情页和预览一致。

## 在 MacBook 上操作
```bash
cd frontend && npm run dev
```
打开 `/write`，输入：

```markdown
## 小标题

- 第一项
- 第二项

```python
print("hello")
```
```

## 验证
- 预览区标题、列表、代码块正常。
- 保存后详情页代码块有深色背景和高亮。
- 输入 `<script>alert(1)</script>` 不会执行。

## 踩坑与差异
不要信任前端预览的 HTML；后端必须再渲染并清洗一次。编辑已有文章时，`form.body` 是 Markdown 源文而不是 `body_html`，否则再次保存会把 HTML 当 Markdown 转义。

## 小结
写作体验的核心是“输入不打断思路”，预览只是辅助。
