# 30. Markdown 编辑器

## 本章目标

- 把“富文本”重新解释为 Markdown：作者写纯文本，渲染交给程序。
- 服务端用 Python-Markdown + bleach 生成安全的 `body_html`。
- 前端做左右分栏的实时预览，并用 DOMPurify 再清洗一次。
- 理清保存链路：标题、正文、栏目、标签、封面各自什么时候提交。

## 原教程怎么做

原教程在后台和前台的“富文本编辑器”章节里引入 CKEditor，让作者在带按钮的可视化编辑器里排版，再把生成的 HTML 存进数据库。它还处理代码高亮和编辑器宽度自适应。这个方案对不熟悉 Markdown 的作者友好，但存的是 HTML，后期清洗、迁移和搜索都比纯文本麻烦。

## 本实作怎么做

本实作没有装 CKEditor，正文存的是 Markdown 源码，渲染在服务端完成。核心在 `backend/blog/utils.py`：

```python
MD_EXTENSIONS = ["fenced_code", "codehilite", "toc", "tables"]
html = markdown.markdown(text, extensions=MD_EXTENSIONS, extension_configs=MD_EXTENSION_CONFIGS)
return bleach.clean(html, tags=ALLOWED_TAGS, attributes=ALLOWED_ATTRIBUTES, protocols=ALLOWED_PROTOCOLS, strip=True)
```

`fenced_code` 支持代码块，`codehilite` 生成高亮所需的 class，`toc` 生成标题 id，`tables` 支持表格。`bleach` 用白名单过滤标签和属性，脚本、事件处理器、危险协议都会被去掉。`Article.save()` 每次都会重新计算 `body_html`，所以正文改了，渲染结果一定跟着变。

前端编辑器在 `frontend/src/components/ArticleEditor.vue`，左边是输入区，右边是预览区：

```js
const previewHtml = computed(() => renderMarkdown(form.body))
```

`frontend/src/utils/markdown.js` 用 `marked` 解析，再用 `DOMPurify.sanitize` 清洗。服务端和客户端各清洗一次不是重复劳动：服务端保证入库内容安全，客户端保证即时预览不会在浏览器里执行意外脚本。

工具栏提供 H1、H2、加粗、斜体、链接、代码块、引用、列表。`wrap()` 在选区两侧插标记，`insertBlock()` 在光标处插入整块内容，两者都会把焦点还给 textarea。预览区用 `MarkdownBody` 渲染，和服务端详情页共用同一套 `.prose` 样式。

保存时 `ArticleEditor` 组装 `{title, body, column, tags}`，新建走 `createArticle`，编辑走 `updateArticle`；如果选了封面，再调用 `uploadArticleCover`。保存成功后跳转到详情页，读者看到的是服务端渲染的 `body_html`，不是前端的预览结果。

## 验证

- `.venv/bin/python manage.py test blog.tests.ArticleApiTests.test_author_can_create_with_tags_and_column`：创建带标题的正文后，`toc` 长度应为 1。
- 在正文里写 `<script>alert(1)</script>`，保存后详情页不应执行脚本，HTML 里也不应保留该标签。
- 写一个表格和代码块，详情页应正常显示，代码块带 `codehilite` 的 class。
- 编辑文章只改正文，保存后 `body_html` 应更新，目录也应重新生成。

## 踩坑与差异

- 原教程存 HTML、用 CKEditor；这里存 Markdown，编辑器和渲染器是两套代码，但数据更干净，搜索和迁移都容易。
- 前端 `marked` 和后端 Python-Markdown 对极端语法的处理不完全一致，预览和最终页面可能有细微差异；常见语法没问题，复杂嵌套要以服务端结果为准。
- 正文里插入图片目前只能写外链 Markdown，编辑器没有图片上传按钮；封面是单独字段，不等于正文图。
- 没有自动保存和草稿。刷新页面会丢未发布的正文，长文写作要先在本地留底。
- 代码高亮的样式依赖前端引入的 highlight.js CSS；如果样式没加载，`codehilite` 只是普通的等宽块。
