# 28. 标签

## 本章目标
- 给文章打多个标签。
- 按标签筛选文章。
- 在列表、详情、侧栏显示标签。

## 原教程怎么做
原教程用 `django-taggit`，在 Model 里加 `tags = TaggableManager(blank=True)`，写文章时接收标签，列表页用 `tags__name__in` 过滤。

## 本实作怎么做
模型保持 taggit：

```python
from taggit.managers import TaggableManager
tags = TaggableManager(blank=True)
```

序列化器自定义 `TagsField`：读取时返回字符串数组，写入时接受数组并去重。创建/更新时：

```python
tags = validated_data.pop("tags", [])
article = Article.objects.create(...)
article.tags.set(tags)
```

列表过滤在 `ArticleViewSet.get_queryset()`：

```python
tag = self.request.query_params.get("tag")
if tag:
    queryset = queryset.filter(tags__name__in=[tag]).distinct()
```

`GET /api/tags/` 返回 `{name, slug}`，前端 `TagView` 用路由参数 `slug` 请求文章列表；`SidebarPanel` 渲染标签云。

## 在 MacBook 上操作
```bash
cd backend && source .venv/bin/activate
python manage.py shell -c "from taggit.models import Tag; print(Tag.objects.count())"
```
写入文章时传 `"tags": ["Django", "Vue"]`，再访问 `/tag/Django`。

## 验证
- 同一篇文章重复标签只保存一次。
- 标签过滤结果只包含带该标签的文章。
- 标签页空结果时显示空状态，不报错。

## 踩坑与差异
taggit 的 `slug` 对中文标签可能为空或重复，前端用 `slug || name` 兜底；后端过滤用 `name`，所以中文标签也能工作。

## 小结
标签是轻量的横向分类，和“栏目”这种纵向归档互补。
