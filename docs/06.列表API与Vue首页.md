# 06. 列表 API 与 Vue 首页

## 本章目标
- 用 `ArticleViewSet` 提供文章列表与详情。
- 让序列化器输出摘要、评论数、作者、栏目和标签。
- 配好分页、搜索、排序参数。
- 用 `ArticleFeed` 和 `HomeView` 渲染首页。

## 原教程怎么做
原教程改写 `article_list`：`ArticlePost.objects.all()` 取出全部文章，塞进 `context`，`render(request, 'article/list.html', context)`；模板里用 `{% for article in articles %}` 逐条输出标题。没有分页，也没有 JSON。

## 本实作怎么做
列表由 `backend/blog/views.py` 的 `ArticleViewSet` 负责。它继承 `ModelViewSet`，`lookup_field = "slug"`，所以详情地址是 `/api/articles/<slug>/` 而不是 id。列表查询做了三件事：关联作者与栏目、预取标签、注解有效评论数：
```python
def get_queryset(self):
    queryset = (
        Article.objects.select_related("author", "author__profile", "column")
        .prefetch_related("tags")
        .annotate(comment_count=Count("comments", filter=Q(comments__active=True)))
    )
    column = self.request.query_params.get("column")
    if column:
        queryset = queryset.filter(column__slug=column)
    tag = self.request.query_params.get("tag")
    if tag:
        queryset = queryset.filter(tags__name__in=[tag]).distinct()
    return queryset
```
`search_fields = ["title", "body"]`、`ordering_fields = ["created", "updated", "total_views", "likes", "title"]`，配合 DRF 的 `SearchFilter`、`OrderingFilter`，前端可以直接传 `?search=`、`?ordering=-total_views`。分页由 `blog/pagination.py` 的 `DefaultPagination` 控制，默认 `page_size=6`，最大 50。

`backend/blog/serializers.py` 的 `ArticleSerializer` 输出 `excerpt`（`make_excerpt(body)`）、`comment_count`、`author.avatar`、`column`、`tags` 等字段，列表项形状与 `SPEC.md` 一致。

前端 `frontend/src/components/ArticleFeed.vue` 负责拉数据：
```js
const data = await listArticles({ page: page.value, page_size: 6, ...props.filters })
items.value = data.results
count.value = data.count
totalPages.value = Math.max(1, Math.ceil(data.count / 6))
```
`frontend/src/views/HomeView.vue` 只组合 hero 和列表：
```vue
<ArticleFeed kicker="Latest" title="最近写了什么" :show-sidebar="true" />
```
侧栏由 `SidebarPanel.vue` 提供搜索、最热、栏目、标签；文章卡片是 `ArticleCard.vue`。

## 在 MacBook 上操作
后端和前端各开一个终端：
```bash
cd ~/work/django-vue-blog/backend
source .venv/bin/activate
python manage.py runserver 127.0.0.1:8000
```
```bash
cd ~/work/django-vue-blog/frontend
npm run dev
```
Vite 跑在 5173，`vite.config.js` 把 `/api`、`/media`、`/static` 代理到 8000。打开 <http://127.0.0.1:5173/> 就能看到首页。

我实际用测试客户端请求 `/api/articles/?page_size=2`，返回 200，响应键是 `count`、`next`、`previous`、`results`，`results` 长度为 2，说明分页参数生效。

## 验证
首页应显示文章卡片，默认每页 6 篇，底部有分页条；切换页码会重新请求。搜索框跳 `/search?q=`，最热列表来自 `/api/articles/hot/`。直接请求 `/api/articles/?search=Django` 或 `?ordering=-total_views`，结果应相应过滤和排序。数据库为空时首页显示空状态，不会白屏。

## 踩坑与差异
- 原教程把文章对象直接交给模板循环；这里输出 JSON，Vue 用 `ArticleFeed` 渲染，模板语法换成 `v-for`。
- 原教程这一章没有分页；本实作加了 `PageNumberPagination`，前端按 `count` 自己算总页数。
- 列表查询必须 `select_related`/`prefetch_related`，否则每张卡片都会额外查作者、栏目和标签。
- `comment_count` 只统计 `active=True` 的评论，软删除的评论不会出现在数字里。除此之外本章没有遇到额外问题。
