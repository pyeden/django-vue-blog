# 38. 前端格式化

## 本章目标

- 把日期、相对时间、数量这些展示逻辑收进一个工具模块。
- 用组件处理头像，没有头像时也有稳定的占位。
- 让摘要由后端生成，前端不重复解析 Markdown。
- 知道 Vue 3 没有模板过滤器后，代码该怎么组织。

## 原教程怎么做

原教程在 app 下建 `templatetags/`，注册 `Library`，写 `time_since_zh` 之类的过滤器，模板里用 `{{ article.created|time_since_zh }}`。标签则用来循环或生成目录。逻辑跟着模板走，换页面就要重新加载标签库。

## 本实作怎么做

Vue 3 移除了模板过滤器，`{{ value | filter }}` 不再可用。本实作把格式化写成普通函数，放在 `frontend/src/utils/format.js`，组件显式导入调用。

日期有三个层次：

```js
formatDate(value)      // 2026年11月9日
formatShortDate(value) // 2026.11.09
formatDateTime(value)  // 2026年11月9日 12:29
```

实现都用 `Intl.DateTimeFormat('zh-CN', ...)`，不引 dayjs。`formatShortDate` 目前没有页面使用，是留给归档列表的备用函数；不确定要不要用的时候，不要为了“以后可能”先塞进模板。

相对时间给通知用：

```js
const formatter = new Intl.RelativeTimeFormat('zh-CN', { numeric: 'auto' })
return formatter.format(rounded, unit)
```

`fromNow` 先算秒差，再按 60、60、24、7、4.345、12 逐级换算，小于一秒返回“刚刚”。未来时间会得到“3天后”这样的结果，不会出现负数文案。

数量格式只有一个小函数 `pluralCount(count, unit)`，输出“6 条评论”“43 篇”。它不做英文单复数，因为站点是中文。

头像在 `UserAvatar.vue`。有 `avatar` 时走 `mediaUrl()`，没有时用 `initials(name)`：中文取最后一个字，英文取首字母大写。背景色由 `avatarTone(name)` 对名字做哈希，映射到 0–359 的色相，再固定饱和度和亮度，保证同一用户每次颜色一致，也不会出现刺眼的纯色。

摘要不放在前端。`backend/blog/utils.py` 的 `make_excerpt()` 先去掉代码块、图片、链接语法和标题符号，再压缩空白，截到 120 字加省略号。列表接口直接返回 `excerpt`，`ArticleCard.vue` 只管显示。这样首页不用加载整篇 Markdown，也不用在前端再跑一次解析。

`plainText()` 也在 `format.js` 里，作用是去 HTML 标签并截断，目前没有调用；它和 `make_excerpt` 有重叠，保留是因为有些第三方摘要可能需要。写教程时标清楚“未使用”，比假装它是核心链路诚实。

## 在 MacBook 上操作

改完工具函数后跑构建：

```bash
cd ~/work/django-vue-blog/frontend
npm run build
```

构建能过只说明语法和导入没问题。格式化结果要在页面上看：

```bash
npm run dev
```

打开首页看文章日期，打开通知页看“x 分钟前”，打开评论看“2026年11月9日 12:29”。

## 验证

- 同一篇文章刷新两次，日期格式不变，不出现 `Invalid Date`。
- 通知时间显示“刚刚”“1 分钟前”这类相对文案，而不是原始 ISO 字符串。
- 没有头像的账号显示一个字，背景色稳定；换一个账号颜色不同。
- 列表卡片的摘要没有井号、星号、反引号这些 Markdown 符号，也没有整段代码。
- 把系统时区改成其他时区，`Intl` 输出会跟着本地时区变化；后端统一存 UTC，前端负责按用户本地时间展示。

## 踩坑与差异

第一个坑是时区。后端 `USE_TZ=True`，API 返回带时区的 ISO 字符串；`new Date(value)` 能正确解析。如果后端返回 `"2026-11-09 12:29:00"` 这种没有时区的字符串，Safari 可能按本地时间解释，Chrome 可能按 UTC，格式就会差几个小时。保持 ISO 8601 是底线。

第二个坑是 `Intl.RelativeTimeFormat` 的单位。传 `'day'` 而不是 `'days'`，传错会直接抛错。`fromNow` 里的单位表是手写的，改的时候要一起测。

第三个差异是模板过滤器没了。原教程可以在模板里链式 `|date|lower`，Vue 里要写成 `formatDate(value).toLowerCase()` 或组合函数。这不是退步，逻辑从模板回到了可测试的 JavaScript。

第四个坑是头像 URL。`mediaUrl()` 遇到 `http://` 或 `https://` 会原样返回，遇到相对路径才拼 `VITE_MEDIA_BASE`。生产环境序列化器返回的是绝对地址，所以这个分支通常走不到；本地开发返回 `/media/...`，Vite 代理会接住。两条路径都要测。
