# 01. 为什么重做

原教程《Django 博客教程》写得很完整，但它停在 Django 2.2 + Bootstrap 模板的时代：视图函数返回 `render()`，页面靠模板继承和 jQuery Ajax 拼接。今天再照着敲，会遇到三个现实问题：

1. Django 2.2 已经停止维护，Python 3.7 在 macOS 上也不好装。
2. 模板 + jQuery 的写法与现在前后端分离的工程习惯脱节。
3. 原教程按 Windows 写命令，Mac 上路径、虚拟环境激活、换行符都要改。

所以我在 MacBook 上按它的功能顺序重做了一遍，技术选择如下：

- 后端：Python 3.12 + Django 4.2 LTS + Django REST Framework
- 前端：Vue 3 + Vite + Pinia + Vue Router + Bootstrap 5
- 数据库：SQLite（够个人博客用，部署时再换 MySQL/PostgreSQL 也容易）
- 部署：gunicorn + nginx 子路径 `https://seres-ai.com/djangovueblog/`

这套组合的好处是：Django 仍然负责“数据、权限、后台”，Vue 负责“页面和交互”，两边通过 JSON API 解耦。原教程里每一章的知识点都还在，只是实现位置变了。每章开头我会写清楚“原教程怎么做 / 本实作怎么做”，避免你对着旧代码找不到对应关系。

最终可访问的项目：<https://seres-ai.com/djangovueblog/>
