# 41. 总结

## 这一遍做完了什么
- Django 4.2 + DRF 后端：文章、栏目、标签、封面、分页、搜索、浏览量、点赞、两级评论、通知、用户资料、头像、密码重置、删除账号。
- Vue 3 + Vite 前端：首页、详情、写作/编辑、登录注册、个人资料、搜索、栏目/标签归档、通知、404。
- 50 个后端测试；17 项 API 冒烟；本地截图验收。
- Mac mini 上的 gunicorn + launchd + nginx 子路径部署。

## 和原教程最大的不同
1. 原教程是 Django 模板 + Bootstrap 4；本实作是 DRF + Vue 3。模板章节对应的知识落到了“序列化器、API、组件、路由”上。
2. 原教程在 Windows 上开发；本实作所有命令都在 macOS 上重跑，虚拟环境、路径、权限都按 Mac 改。
3. 原教程部署到独立云服务器；本实作挂到既有 `seres-ai.com` 的 `/djangovueblog/` 子路径，复用 nginx 与 frp。

## 还没做的
- GitHub OAuth 第三方登录没有启用（需要 OAuth App 凭据）。
- 文章上下篇快捷导航没有做，详情页用目录和侧栏替代。
- 生产密码重置仍用 console backend，需要配置 SMTP 才能真发邮件。
- SQLite 适合个人博客；流量上来后应换 PostgreSQL/MySQL，并做备份。

## 下一步建议
先让站点稳定跑一段时间，观察真实访问和评论；再决定做邮件、对象存储、全文搜索或评论审核。不要一开始就把所有“轮子”装上。

## 写在最后
教程的价值不在代码量，而在“每一步都能复现”。这份重写版里的命令、报错和部署细节都来自这次在 MacBook / Mac mini 上的实际过程；如果环境不同，先对齐版本，再逐章验证。
