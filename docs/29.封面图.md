# 29. 封面图

## 本章目标
- 文章可以有封面图。
- 写作/编辑时可以上传、预览、替换。
- 列表和详情正确显示封面。

## 原教程怎么做
原教程用 `ImageField` + Pillow，在表单里上传，模板里 `article.avatar.url` 显示，并用 imagekit 做缩略图。

## 本实作怎么做
`Article.cover = models.ImageField(upload_to="covers/", blank=True, null=True)`。文章创建/更新仍走 JSON；封面单独走 multipart 接口，避免把 Markdown 和文件混在一个请求里：

```python
@action(detail=True, methods=["post"], url_path="cover",
        parser_classes=[MultiPartParser, FormParser])
def cover(self, request, slug=None):
    article = self.get_object()
    self.check_object_permissions(request, article)
    article.cover = request.FILES["cover"]
    article.save(update_fields=["cover"])
    return Response(self.get_serializer(article).data)
```

前端 `CoverUpload.vue` 用 `URL.createObjectURL` 预览，保存文章后调用 `uploadArticleCover(slug, file)`。列表卡片只在有封面时显示缩略图，没有封面时不占位。

## 在 MacBook 上操作
上传接口需要 `python-multipart` 由 DRF 自带处理；确认 `Pillow` 已安装：
```bash
pip show pillow
```

## 验证
- 新建文章时选一张图，保存后详情页出现封面。
- 编辑文章换图，旧图不被引用。
- 未登录上传返回 403。

## 踩坑与差异
`ArticleSerializer` 的 `cover` 是只读 `SerializerMethodField`，所以不能直接在创建 JSON 里塞文件；这就是单独开 `cover` action 的原因。生产环境建议在保存时用 Pillow 压缩到最大宽度 1600px。

## 小结
封面是列表页的第一视觉锚点，但不要让它压过标题。
