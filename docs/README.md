# 从零构建一个 Django + Vue 个人博客

这是一套从问题出发的构建笔记：先决定要做一个什么样的博客，再一层层把数据、API、页面、测试和部署搭起来。每一章都能在 macOS 上复现，代码就是仓库里的 `backend/` 与 `frontend/`。

## 技术栈

- Python 3.12 + Django 4.2 LTS + Django REST Framework
- Vue 3 + Vite + Pinia + Vue Router + Bootstrap 5
- SQLite（个人博客够用，后续可换 PostgreSQL）
- gunicorn + nginx 子路径部署

## 读者假设

这套笔记默认你：

- 会用鼠标、装软件、打开终端；
- 没学过 Django，也没学过 Vue；
- 每天能拿出 1–2 小时，愿意跟着敲，而不是只读。

如果完全不熟悉终端，先记住三件事：`cd` 是进入目录，`ls` 是看目录里有什么，`pwd` 是看自己现在在哪。每章的命令都会写清楚“在哪个目录执行”。

每章大约 1–2 小时；第 12 章部署第一次做可能需要半天，建议单独留出时间。

## 学习方式

1. 先读“先补概念”：不要求背，但要知道这个词大概指什么。
2. 再跟着“手把手步骤”敲：不要复制一大段，先一行一行执行。
3. 做到“检查点”再往下：检查点没过，后面的错误会叠在一起。
4. 报错先看“常见错误”：里面写的是真实报错、原因和修复方式。
5. 每章末尾的“小结”用来回顾，不用背。
