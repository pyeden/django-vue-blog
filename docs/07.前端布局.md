# 07. 前端布局

## 本章目标
- 用 CSS 变量定义纸张、墨色、强调色的设计系统。
- 搭出首页、列表页和详情页共用的栅格。
- 让文章卡片支持有封面和无封面两种形态。
- 用媒体查询处理 991px、767px 两个断点。

## 原教程怎么做
原教程下载 Bootstrap 4 的 css/js，放进 `static/bootstrap/`，再写 `base.html`、`header.html`、`footer.html` 三个模板，用 `container`、`card`、`navbar` 这些类拼页面，靠 jQuery 处理交互。

## 本实作怎么做
本实作没有 Django 模板继承，布局落在 Vue 组件和一份全局样式上。`frontend/src/main.js` 按顺序引入 Bootstrap 5、Bootstrap Icons、highlight.js 主题，最后是 `src/assets/styles/main.css`：
```js
import 'bootstrap/dist/css/bootstrap.min.css'
import 'bootstrap-icons/font/bootstrap-icons.css'
import 'highlight.js/styles/atom-one-dark.css'
import './assets/styles/main.css'
```
`frontend/src/App.vue` 固定了页面骨架：`AppHeader`、`main.app-main`（里面是 `router-view`）、`AppFooter`、`BackToTop`、`ToastHost`。

设计变量集中在 `main.css` 的 `:root`：
```css
:root {
  --paper: #faf6ee;
  --ink: #211d18;
  --accent: #a9482a;
  --header-h: 72px;
  --serif: "Iowan Old Style", "Songti SC", "Noto Serif SC", serif;
}
```
页面宽度用 `.container-narrow` 限制在 1180px。首页主体是两栏：
```css
.layout-grid {
  display: grid;
  grid-template-columns: minmax(0, 1fr) 318px;
  gap: 54px;
  align-items: start;
}
.layout-side {
  position: sticky;
  top: calc(var(--header-h) + 26px);
}
```
文章卡片按“封面 150px + 内容”排：
```css
.article-card {
  display: grid;
  grid-template-columns: 150px minmax(0, 1fr);
  gap: 24px;
  padding: 27px 0;
  border-bottom: 1px solid var(--line);
}
.article-card.no-cover { grid-template-columns: 1fr; }
```
没有封面时 `ArticleCard.vue` 会给根节点加 `no-cover`，卡片自动变成单栏，不会留一块空白。

`App.vue` 只负责外壳，页面内部各管各的布局：首页用 `hero-grid` 加 `layout-grid`，详情页用 `article-layout`，写作页用 `editor-grid`。`site-header` 是 `position: sticky`，滚动时一直贴在顶部；`layout-side` 也做了 sticky，但顶部偏移要加上 `--header-h`，否则会被导航栏盖住。字号体系用 `--serif` 和 `--sans` 两套，标题用衬线，正文用系统无衬线，中文回退到 `Songti SC` 和 `PingFang SC`。

## 在 MacBook 上操作
```bash
cd ~/work/django-vue-blog/frontend
npm run dev
```
打开 <http://127.0.0.1:5173/>。改 `main.css` 后 Vite 会热更新，不用重启。需要出生产包时执行 `npm run build`，产物在 `frontend/dist/`；这一步会写文件，我只在部署前跑。

`main.css` 里的颜色、间距、阴影都走变量，组件里只写 `var(--accent)` 这类引用。Bootstrap 只提供栅格、按钮、表单的基础样式，视觉部分由自定义类接管，所以不会出现“Bootstrap 默认蓝”到处跑。`index.html` 的 `theme-color` 和 favicon 也跟随纸张色，移动端地址栏不会突然变白。

## 验证
把浏览器窗口从宽屏缩到 900px 左右，`layout-grid` 应变成单栏，侧栏从粘性定位改为静态；缩到 700px 以下，文章卡片封面变成 104px，导航栏的二级标题和导航链接隐藏。详情页在 991px 以下会隐藏右侧目录栏。检查 `document.querySelector('.layout-grid')` 的计算样式，能直接看到 `grid-template-columns` 的变化。

检查响应式时不要只看首页：详情页在 991px 以下会把 `article-layout` 收成一栏并隐藏 `toc-rail`；写作页的 `editor-grid` 也会从两栏变一栏，预览区落到编辑区下方。`article-card` 在 767px 以下封面缩到 104×88，标题字号降到 1.22rem；如果文字被截断，检查 `-webkit-line-clamp` 是否被其他样式覆盖。

## 踩坑与差异
- 原教程是 Bootstrap 4 + jQuery，本实作是 Bootstrap 5 + Vue，没有 jQuery，也没有 `bootstrap.min.js` 的 DOM 操作。
- 原教程用 `{% static %}` 引静态文件；Vite 直接 `import`，构建时自动加 hash。
- 全局样式必须在 Bootstrap 之后引入，否则 `.btn-ghost`、`.container-narrow` 这类自定义类会被覆盖。
- 颜色全部走 CSS 变量，后面改主题只动 `:root`，不要在组件里写死色值。
- 原教程的 `static/bootstrap/` 目录不再需要，Bootstrap 由 npm 安装、Vite 打包。
- 自定义类名不要和 Bootstrap 的 `.card`、`.btn` 混用，否则优先级很难查；本项目用 `article-card`、`btn-ghost` 这类前缀。
- `backdrop-filter` 在部分旧浏览器不生效，但会退化成半透明背景，不影响可读性。

首页 hero 区在 991px 以下会变成单列，右侧统计块移到正文下方，不会和标题挤在一起。

页面没有引入 jQuery，所有交互由 Vue 组件自己处理，Bootstrap 只当样式库用，不参与 DOM 操作。
