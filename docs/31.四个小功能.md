# 31. 四个小功能

## 本章目标

- 给长文章加一个回到顶部的浮动按钮。
- 让首页侧栏、文章目录在滚动时保持可见。
- 页脚在内容不足一屏时也贴在底部。
- 用矢量图标替代原教程里的图片图标。

## 原教程怎么做

原教程用 jQuery 监听 `window.scroll`，控制 `#BackTop` 的淡入淡出，滚动用 `animate({scrollTop:0})`。粘性侧栏靠 Bootstrap 的 `sticky-top`，页脚用 flex 布局压到底部，图标则是下载一套字体图标后写 `<i>` 标签。

## 本实作怎么做

这四个功能在 Vue 里都变成了组件或全局样式，不再拼 DOM。

回到顶部是 `frontend/src/components/BackToTop.vue`。它用 `window.scrollY` 判断是否显示，用原生 `window.scrollTo` 平滑滚动：

```js
const visible = ref(false)
function onScroll() { visible.value = window.scrollY > 420 }
function toTop() { window.scrollTo({ top: 0, behavior: 'smooth' }) }
```

按钮通过 `<transition name="backtop">` 包起来，进出场只改透明度和位移，没有 jQuery 的 `fadeIn`。`App.vue` 把它挂在页面最外层，所以每个路由都有。按钮的 `z-index` 是 1500，低于 toast 的 2000、高于顶栏的 1000，这样不会被内容遮住，也不会压住提示消息。

按钮本身不参与文档流，`position: fixed` 固定在视口右下角。它只在 `visible` 为真时渲染，路由切换时组件不会销毁，所以滚动位置会延续；这正好符合“在文章页滚到一半，点按钮回顶部”的预期。

侧栏粘性在 `frontend/src/assets/styles/main.css`：

```css
.layout-side { position: sticky; top: calc(var(--header-h) + 26px); }
.toc-rail { position: sticky; top: calc(var(--header-h) + 28px); }
.site-header { position: sticky; top: 0; z-index: 1000; }
```

`top` 要加上 `--header-h`，否则侧栏会被固定顶栏盖住。文章页的目录栏同理。

页脚沉底靠 flex，而不是算高度：

```css
.app-frame { display: flex; flex-direction: column; min-height: 100vh; }
.app-main { flex: 1 0 auto; }
```

`AppFooter.vue` 只负责内容：站点名、首页、搜索、源码链接和年份。年份用 `new Date().getFullYear()`，不需要后端传。页脚链接使用 `router-link`，站内跳转不会触发整页刷新；只有“源码”是普通 `<a>`，因为要打开 GitHub。

页脚文案里的站点名来自 `VITE_BLOG_TITLE`，默认值是“纸上集”。这样同一套代码换一个博客时，只改环境变量，不用改组件。

图标全部来自 `bootstrap-icons`，在 `main.js` 里引入一次：

```js
import 'bootstrap-icons/font/bootstrap-icons.css'
```

页面里写 `<i class="bi bi-arrow-up"></i>`、`bi-bell`、`bi-heart` 即可，不再维护图片资源。图标的尺寸跟随父元素字号，颜色用 `currentColor`，所以按钮 hover 变红时图标也跟着变，不需要准备两套图片。

## 在 MacBook 上操作

```bash
cd ~/work/django-vue-blog/frontend
npm run dev
```

Vite 配置的端口是 5173。打开首页，把窗口缩窄，确认侧栏和页脚没有错位。

构建验证：

```bash
npm run build
```

构建产物在 `frontend/dist/`。这一步只验证编译，不验证视觉效果。

## 验证

- 首页向下滚动超过 420 像素，右下角出现圆形箭头按钮；点击后回到顶部。
- 文章页右侧目录在滚动时停在顶栏下方，不跟着正文滚走。
- 打开一篇很短的 404 页面，页脚仍在窗口底部，不会悬在中间。
- 顶栏铃铛、点赞心形、页脚图标都能显示；断网时也不会出现裂图，因为它们是字体图标。
- 在浏览器开发者工具里把窗口高度调到 500px 左右，页脚仍应贴在内容之后；如果页面内容很短，页脚会落在视口底部，而不是紧跟在标题下面。

## 踩坑与差异

原教程用 jQuery，Vue 3 项目里没有 jQuery，也不应该为了一个按钮引入。`scroll` 监听要加 `{ passive: true }`，并在 `onBeforeUnmount` 移除，否则路由切换后会残留监听器。

按钮的 `bottom` 设为 82px，是为了避开右下角 24px 的 toast 区域；手机上再降到 76px。这个数值不是随手写的，改 toast 位置时要一起调。

粘性定位常见的坑是父容器有 `overflow: hidden`，会让 `sticky` 失效。本项目的 `.layout-grid` 和 `.article-layout` 都没有设这个属性。另一个坑是父容器高度不够：如果侧栏比正文高，滚动到底部时它会提前停住，这是 `sticky` 的正常行为，不是 bug。

顶栏的 `z-index` 是 1000，目录栏没有单独设 `z-index`，因为它只需要在正文右侧待着。两者叠在一起时，顶栏必须在上层，否则滚动时目录文字会穿过顶栏。
